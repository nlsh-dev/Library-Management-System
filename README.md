# 📚 Library Management System

A simple **Library Management System** developed in Java using Object-Oriented Programming (OOP) concepts.

This project allows users to manage books and library users through an interactive console-based menu.

---

## 🎯 Objective

The objective of this project is to build a mini Library Management System while understanding and applying core Java OOP concepts.

The system provides functionality to:

- Add books
- Add library users
- Display available books
- Display registered users
- Issue books to users
- Return books
- Handle invalid operations

---

## 🛠️ Technologies Used

- Java
- IntelliJ IDEA / VS Code
- Terminal / PowerShell
- Git
- GitHub
